# Phase 4 — UI Design Contract: Compare View

> Visual and interaction contract for the /compare/[origin]/[dest] screen.
> Generated by gsd-ui-researcher. This is the COPRRRA demo centrepiece — every decision
> here must serve a 6-minute live presentation to 40–50 climate researchers and policymakers.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — custom Tailwind v4 + OKLCH token system |
| Preset | not applicable |
| Component library | none — all components hand-built in this codebase |
| Icon library | none — text-based labels and Unicode arrows only (project pattern) |
| Font — Display | Playfair Display SC (`font-display`) — large numeric values |

## Layout Contract

### Shell

The Compare View exits the three-panel command center shell entirely. It does NOT render
RegionTree or IntelligencePanel. The shell is:

```
┌──────────────────────────────────────────────────────────────────┐
│ CommandBar — fixed top, 48px (--bar-height), unchanged           │
├──────────────────────────────────────────────────────────────────┤
│ COMPARISON HEADER — full-width, 64px min-height                  │
│ [← Command Center]  [Origin name] vs [Dest name]  [DTM count]   │
├────────────────────────────┬─────────────────────────────────────┤
│   LEFT PANEL — SIDS origin │   RIGHT PANEL — Australian dest     │
│   flex-1 (50%)             │   flex-1 (50%)                      │
│  ┌──────────────────────┐  │  ┌──────────────────────────────┐   │
│  │  CompareMiniMap      │  │  │  CompareMiniMap              │   │
│  │  h-[280px], static   │  │  │  h-[280px], static           │   │
│  │  dark terrain tiles  │  │  │  dark terrain tiles          │   │
│  └──────────────────────┘  │  └──────────────────────────────┘   │
│  ── panel data modules ──  │  ── panel data modules ──           │
│  Displacement count        │  Flood risk score                   │
│  Displacement trend        │  Flood depth (100yr return)         │
│  Coastline status          │  Flood zone area                    │
└────────────────────────────┴─────────────────────────────────────┘
│ StatusStrip — fixed bottom, 32px (--strip-height), demoMode=true │
└──────────────────────────────────────────────────────────────────┘
```

## Typography

Exactly 4 declared sizes. All sizes are exact. Do not round or substitute.

| Size | Roles | Font | Weight | Line Height / Tracking |
|------|-------|------|--------|------------------------|
| 28px | DTM count value; all primary panel numeric values (displacement count, trend, flood risk, flood depth) | Playfair Display SC (`font-display`) | 400 | 1.0 |
| 22px | Comparison heading (region names in header) | Syne (`font-syne`) | 700 | 1.15 |
| 13px | Data module units ("m", "%", "km²", "people") | JetBrains Mono (`font-mono`) | 400 | 1.0 |
| 9px | ALL mono labels: DTM count label, panel section headings, data module labels, back nav link, mini-map caption, source attribution, module subtext, loading aria-labels | JetBrains Mono (`font-mono`) | 400 | 1.4; tracking-[0.14em]–[0.18em] uppercase where labelling |

**Consolidation notes (checker-mandated):**
- 8px source attribution, 9px data labels, 10px panel section headings — all unified to 9px. At mono uppercase tracked, these sizes are perceptually identical and serve the same label role.
- 36px data module values and 28px DTM count — both unified to 28px. One numeric size creates visual rhythm across both panels and the header.
- 20px mobile region name variant is dropped. Handle responsively with Tailwind: `text-[18px] md:text-[22px]` on the Syne heading. 18px and 20px are NOT declared sizes.

**Font weight rule:** Only two weights in use — 400 (regular) and 700 (bold). No exceptions.

**Responsive heading rule:** Region names in comparison header use `text-[18px] md:text-[22px]` — the 18px is a Tailwind breakpoint override, not a declared type scale size.

## Color

Fully derived from the existing token system in globals.css. No new hex values introduced.

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--ocean` | `#0D1B2A` | Page background, CommandBar bg, StatusStrip bg |
| Secondary (30%) | `--surface` / `--surface2` | `#152236` / `#1C2E45` | Panel column backgrounds, data module card backgrounds |
| Accent — migration/SIDS (left panel) | `--teal` | `#4CB9C0` | Left panel section heading, SIDS RegionTypeBadge border/text, displacement count value, mini-map caption border, panel divider accent line |
| Accent — flood/AUS (right panel) | `--gold` | `#D4A55A` | Right panel section heading, FLOOD ZONE RegionTypeBadge border/text, flood risk score value |
| Semantic — critical risk | `--coral` | `#E05B4B` | CRITICAL risk level text, negative trend indicators, coastline erosion values |
| Semantic — moderate risk | `--sky` | `#3B7DD8` | MODERATE risk level text |
| Text primary | `--text` | `#E8EDF2` | All primary readable content |
| Text secondary | `--text-mid` | `#8BA5BC` | Supporting data, trend descriptions |
| Text tertiary | `--text-dim` | `#4A6680` | Labels, units, source attribution |
| Border | `--border` | `rgba(76,185,192,0.10)` | All module card borders, comparison header bottom border |

### Color differentiation: SIDS (left) vs AUS (right)

This is the critical design decision for this phase. The two panels must be instantly readable
as different contexts without introducing new colors.

- **Left panel (SIDS — existential risk):** teal accent throughout. Section heading, value color for displacement count, mini-map caption badge, left border on data module cards (`border-l-2 border-teal/40`).
- **Right panel (AUS — flood risk):** gold accent throughout. Section heading, value color for flood risk score, mini-map caption badge, left border on data module cards (`border-l-2 border-gold/40`).
- The panel column backgrounds: left panel `bg-surface` (`#152236`), right panel `bg-surface2` (`#1C2E45`) — a 1-stop darker shift. Subtle but readable in the demo context.

Accent reserved for (explicit list):
- Teal: left panel section headings, displacement numeric value, SIDS RegionTypeBadge, comparison header region name (left), mini-map caption (left), panel divider gradient top terminus
- Gold: right panel section headings, flood risk numeric value, FLOOD ZONE RegionTypeBadge, comparison header region name (right), mini-map caption (right), panel divider gradient bottom terminus
- Coral: negative values only (coastline erosion meters, CRITICAL risk tier text)
- Sky: MODERATE risk tier text only

## Panel Divider Contract

The divider between left and right panels is a deliberate identity moment — it cannot be a plain 1px line or it reads as a template layout.

**Specification:**
- Width: 1px
- Color: vertical gradient — `from-teal/30 via-border to-gold/30`
  - Top 33%: teal/30 (SIDS side bleeds into the divide)
  - Middle 34%: var(--border) — neutral
  - Bottom 33%: gold/30 (AUS side bleeds into the divide)
- No gap between panels — the 1px divider IS the separation
- On mobile (stacked): divider becomes a horizontal `border-t border-[var(--border)]` between panels, no gradient

**Implementation:**
```tsx
// PanelDivider.tsx — server component, no interactivity
<div
  className="w-px flex-shrink-0 self-stretch"
  style={{
    background: "linear-gradient(to bottom, oklch(68% 0.14 195 / 0.30), rgba(76,185,192,0.10) 50%, oklch(70% 0.11 45 / 0.30))"
  }}
/>
```

## Comparison Header Contract

The header is the anchor for the entire screen. It must read immediately to an audience who has never seen the product.

**Structure (left-to-right):**
```
[← COMMAND CENTER]   [TUVALU]  vs  [BRISBANE]   [28,400 · IOM DTM · DISPLACEMENT EVENTS]
```

**Exact treatment:**
- Back nav: `font-mono text-[9px] tracking-[0.14em] uppercase text-[var(--text-dim)] hover:text-teal transition-colors` — left-aligned, `Link href="/"`
- "vs" separator: `font-syne text-sm font-400 text-[var(--text-dim)]` — lowercase, subdued
- Origin name: `font-syne text-[18px] md:text-[22px] font-bold text-teal leading-[1.15]`
- Destination name: `font-syne text-[18px] md:text-[22px] font-bold text-gold leading-[1.15]`
- DTM count — value: `font-display text-[28px] text-[var(--text)] leading-none`
- DTM count — label: `font-mono text-[9px] tracking-[0.14em] uppercase text-[var(--text-dim)]`
- DTM count — source badge: inline `· IOM DTM` or `· IDMC` in teal/40 when source="dtm", text-mid when source="supabase_fallback"
- Header background: `bg-surface/80 backdrop-blur-sm border-b border-[var(--border)]`
- Min-height: 64px, `flex items-center px-6 gap-6`
- Header is a server component — receives data as props from `ComparePage`

**Collapsed (mobile ≤768px):**
- Row 1: back nav left / region names centre using `text-[18px]` (Tailwind breakpoint minimum of the declared 22px size)
- Row 2: DTM count right-aligned — value at 28px / label at 9px

## Mini-Map Contract

Each panel contains one `CompareMiniMap` — a purpose-built raw Leaflet client component.
Do NOT reuse MapCanvas or MapCanvasClient.

**Visual spec:**
- Height: 280px (desktop), 220px (tablet 1024px), 180px (mobile stacked)
- Width: 100% of parent panel column
- Tiles: dark terrain (TILE_URLS.darkTerrain) + labels layer (TILE_URLS.labels, opacity 0.7) — identical to main MapCanvas
- Interaction: all disabled — `zoomControl: false, attributionControl: false, scrollWheelZoom: false, dragging: false, touchZoom: false, doubleClickZoom: false`
- No pointer events overlay needed for MVP — mini-maps are context-only
- Border: none — mini-map bleeds edge-to-edge within the panel column

**Mini-map caption (bottom-left overlay on each mini-map):**
```
[RegionTypeBadge]  TUVALU                     — left mini-map
[RegionTypeBadge]  BRISBANE                   — right mini-map
```
- Position: `absolute bottom-0 left-0 right-0 p-3 flex items-center gap-2`
- Background: `bg-gradient-to-t from-ocean/80 to-transparent` — scrim, not a solid bar
- RegionTypeBadge component: reuse existing, passes `type={region.regionType}`
- Region name: `font-mono text-[9px] tracking-[0.18em] uppercase text-[var(--text)]`

**Loading state:**
- Before Leaflet hydrates: `bg-surface2 animate-pulse` placeholder at the same fixed height
- No spinner — the pulse shimmer matches the existing badge-shimmer pattern

## Data Module Contract

Each panel column renders 3 data modules below the mini-map. Modules are vertically stacked
with `gap-4` (16px = `md` token) internal to the panel's `px-4 py-4` padding.

### Module card base style

Matches the MetricCards pattern exactly:
```
rounded-lg border border-[var(--border)] bg-surface p-4 relative overflow-hidden
```
With a 2px left border accent (teal for left panel modules, gold for right panel modules):
```
style={{ borderLeftColor: accentHex, borderLeftWidth: "2px" }}
```
And a 3% opacity tint background from the accent:
```
<div className="absolute inset-0 pointer-events-none opacity-[0.03]"
     style={{ background: accentHex }} />
```

### Left panel modules (SIDS — origin)

| Module | Label | Value treatment | Data source | Loading state |
|--------|-------|----------------|-------------|---------------|
| Displacement count | DISPLACEMENT EVENTS | `font-display text-[28px] text-teal` + `font-mono text-[13px] text-[var(--text-dim)]` unit "people" | `/api/displacement?country={ISO2}` → `total_displaced` | Skeleton pulse `w-24 h-9 bg-surface2 rounded animate-pulse` |
| Annual trend | DISPLACEMENT TREND | Spark text: "+{n} / year avg" in `font-display text-[28px]`; positive = text-coral (displacement UP = bad), negative = text-teal | `trend[]` from same call | — |
| Coastline status | COASTLINE STATUS | Text-only: "Coastline analysis →" as a Link to `/region/{slug}/coastline`; `font-mono text-[9px] tracking-[0.14em] uppercase text-teal hover:text-teal/80` | Phase 5 will hydrate this; Phase 4 = static link | Not applicable — always static in Phase 4 |

### Right panel modules (AUS — destination)

| Module | Label | Value treatment | Data source | Loading state |
|--------|-------|----------------|-------------|---------------|
| Flood risk score | FLOOD RISK SCORE | `font-display text-[28px] text-gold` + subtext: "100yr return period" in `font-mono text-[9px]` | Derived from `/api/flood-depth?region=brisbane&return_period=100` → depth_m; same score derivation logic as IntelligencePanel | Skeleton pulse |
| Flood depth | FLOOD DEPTH (100YR) | `font-display text-[28px] text-[var(--text)]` + unit "m" in `font-mono text-[13px] text-[var(--text-dim)]` | Same API call, raw `depth_m` | Skeleton pulse |
| Flood zone area | FLOOD ZONE AREA | Static label for MVP: "High-density residential" with a RegionTypeBadge `type="urban_flood"` inline; no live number in Phase 4 | Phase 3 ingest data (not yet surfaced to API as area total); Phase 4 = static descriptor | Not applicable |

### Module animation

Each module card enters with `animate-float-up` at staggered delay:
- Module 0: `animationDelay: "0.05s"`
- Module 1: `animationDelay: "0.12s"`
- Module 2: `animationDelay: "0.19s"`

This matches the MetricCards stagger pattern.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Page `<title>` | `{Origin} vs {Destination} — DEQODE EARTH` |
| Header region comparison | `{Origin name}  vs  {Destination name}` (no "Compare" prefix — the juxtaposition is self-evident) |
| Header DTM label — IOM source | `IOM DTM · DISPLACEMENT EVENTS` |
| Header DTM label — IDMC fallback | `IDMC · DISPLACEMENT EVENTS` |
| Back navigation | `← COMMAND CENTER` |
| Left panel section heading | `CLIMATE DISPLACEMENT` |
| Right panel section heading | `FLOOD RISK INTELLIGENCE` |
| Coastline module link | `Coastline analysis →` |
| Flood zone static descriptor | `High-density residential zone` |
| Loading skeleton aria-label | `Loading {region name} data` |
| Empty displacement (zero count) | Do NOT show 0. Show `No displacement records in database` in `font-mono text-[9px] text-[var(--text-dim)]` with source label. |
| 404 invalid slug — heading | `Region not found` (Next.js notFound() — CommandBar + StatusStrip still render) |
| 404 invalid slug — recovery | `Return to Command Center →` rendered as `<Link href="/" className="font-mono text-[9px] tracking-[0.14em] uppercase text-teal hover:text-teal/80 transition-colors">` below the heading |
| Destructive actions | None in this phase |

**Copywriting rules:**
- All badge/label text is uppercase tracked mono — never sentence case
- Region names in the header are title case: "Tuvalu", "Brisbane" — not "TUVALU"
- Data source is always attributed — never show a number without its source label
- The word "Compare" does not appear on the compare page itself — the layout IS the comparison

## Animation Contract

All animations reuse the existing keyframes in globals.css. No new keyframes introduced.

| Element | Animation | Timing |
|---------|-----------|--------|
| Page entry — comparison header | `animate-float-up` | 0.52s ease-out both |

**Animation law:** No new animation keyframes. The existing EARTH animation system is the complete vocabulary for this phase.
